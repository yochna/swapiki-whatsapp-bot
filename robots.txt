# Swapiki — crawl policy
#
# Everything here is public and intended to be read, including by AI answer
# engines. The job pages are the product's search surface; withholding them from
# a crawler would hide the listings from the people searching for them.
#
# The AI crawlers are listed explicitly rather than left to inherit
# "User-agent: *". That is not because the wildcard does not already cover them -
# it does. It is because each of these operators reads a more specific rule when
# one exists, and because a named, deliberate allow is the difference between
# "we did not think about it" and "we decided this". One line each, no surprises.

User-agent: *
Allow: /
Allow: /jobs
Allow: /jobs.json
Allow: /feed.xml
Allow: /llms.txt
Allow: /llms-full.txt
Allow: /sitemap.xml
Allow: /robots.txt
